
# SITRAC
Sistema Inteligente de Transporte y Gestión de Rutas.

## Descripción
Proyecto desarrollado en C++ para administrar ciudades,
rutas, pasajeros y solicitudes de viaje.

## Estructuras de datos
- Lista enlazada propia.
- Grafo mediante listas de adyacencia.
- Cola enlazada propia.
- Vector para el historial.

## Requisitos
Compilador compatible con C++14 o superior.

## Ejecución
Abrir src/SITRAC.cpp en Dev-C++,
compilar y ejecutar el programa.
